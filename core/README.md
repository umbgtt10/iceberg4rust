# iceberg4rust-core

The analysis behind [`cargo-iceberg4rust`](https://crates.io/crates/cargo-iceberg4rust):
how much private implementation a Rust source file hides beneath its public
surface. This crate is the scoring, the package selection and the report; the
command, `cargo iceberg4rust`, is the `cargo-iceberg4rust` crate.

What it measures, the formula and what to do about a breach are in the
[main README](https://github.com/umbgtt10/iceberg4rust#readme) and
[`docs/FORMULA.md`](https://github.com/umbgtt10/iceberg4rust/blob/main/docs/FORMULA.md).
